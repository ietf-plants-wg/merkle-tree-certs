--- abstract

Merkle Tree Certificates ({{!I-D.ietf-plants-merkle-tree-certs}}) integrate certificate issuance and logging.
This document describes the architecture for using them.
It gives an overview of the entities involved, and the information flows between them.
It also states the security goals, and the assumptions those goals rest on.
